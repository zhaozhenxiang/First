# M2-B 身份与输入链路

- 前置阶段： [M2-A Web 状态基础](/home/x/src/install/php/First/docs/superpowers/specs/2026-04-18-m2a-web-state-foundation-spec.md)

## 目标

在 `M2-A` 已建立的 Web 状态基础上，补齐 `Validation / FormRequest / Auth`，让输入校验、用户解析、认证中间件和失败出口成为同一条可描述的请求链路。

这一阶段的目标不是先追求大量外层语法糖，而是先把“输入何时被校验、用户何时被解析、失败从哪里出去”固定下来。只有这些边界稳定，控制器、异常处理器和响应系统才能共用一套语义。

## 为什么排在 M2-A 之后

`M2-B` 不能跳过 `M2-A` 直接推进。

原因是：

- Session-backed `Auth` 依赖前面已经稳定的 Session / Cookie 恢复语义
- 验证失败后的状态保留、重定向和错误输出依赖统一的 Web 状态基础
- `FormRequest` 的授权与校验如果不站在稳定请求态上，后面会不断返工

因此 `M2-B` 不是平行阶段，而是明确建立在 `M2-A` 之上。

## 范围

### In Scope

- `Validation` 的统一入口、规则执行和失败输出边界
- `FormRequest` 的解析、授权、预处理和已验证输入访问语义
- Session-backed `Auth` guard、当前用户解析和常用认证中间件语义
- 控制器、路由中间件、异常处理器之间的输入与身份联通
- 用测试固定输入与身份主链路

### Out of Scope

- 不在这一阶段扩 token/API auth、OAuth、password reset 或 remember-me
- 不在这一阶段铺开完整 policy / gate / ability 矩阵
- 不在这一阶段引入庞大的 manager / driver / facade 体系
- 不在这一阶段扩 `ORM` 特性，只消费最小必要的数据访问接口
- 不在这一阶段大做前端表单组件或浏览器交互层

## 输入与身份主链路

这一阶段完成后，请求主链路应能稳定描述为：

1. Request 进入 `M1 + M2-A` 已固定的 HTTP 主链路。
2. 输入在进入控制器前经过 `Validation` 或 `FormRequest` 处理，得到明确的成功或失败分支。
3. 当前用户由 `Auth` guard 在 request scope 内解析，而不是在控制器里反复手工恢复。
4. 认证中间件和 guest 中间件在路由层面参与决策，而不是依赖控制器内部约定。
5. 控制器消费的是已经过校验的输入和已经装配好的当前用户。
6. 验证失败、未认证和未授权都从统一异常 / 响应出口转换，而不是各自发明输出路径。

## 设计原则

### 1. 先固定时序，再增加糖衣 API

优先固定输入校验和用户解析在请求链路中的位置，而不是先追求表面 API 丰富度。

### 2. 输入失败与身份失败共用统一出口

验证失败、未认证和未授权都应该进入统一异常处理体系，而不是散落多个临时响应分支。

### 3. 当前用户是 request-scoped 能力

用户解析应绑定在请求生命周期里，而不是通过控制器或 helper 临时恢复。

### 4. `Auth` 建立在 `M2-A` 的状态基础上

Session / Cookie 是 `Auth` 的前置条件，不为认证单独再开一套旁路状态系统。

### 5. 测试要覆盖成功与失败两侧

不仅要测控制器拿到用户和输入，还要测验证失败、未认证和未授权的统一出口。

## 交付物

`M2-B` 完成时，建议至少交付：

1. 一套稳定的 `Validation` 主入口与失败转换规则。
2. 一套可描述的 `FormRequest` 解析、授权与已验证输入访问语义。
3. 一套 Session-backed `Auth` guard 与当前用户解析路径。
4. 一套统一的认证中间件与失败出口行为。
5. 一组能证明输入与身份链路成立的回归测试。

## 验收标准

`M2-B` 结束时，应至少满足：

1. 控制器可以在统一主链路中获得已验证输入，而不是手工分散校验。
2. `FormRequest` 的授权和校验失败都能稳定进入统一异常 / 响应出口。
3. 当前用户可以通过稳定的 request-scoped 解析路径获取，且认证中间件语义一致。
4. 登录态恢复、登出后的状态清理和未认证访问失败都有一致行为。
5. `M2-B` 不要求先扩 `ORM` 能力，也不因为缺少 `ORM` 完整特性而破坏输入与身份主链路。
